A complete build is not permission to replace the current deployed module tree.
Use the guarded live-preservation procedure in `server/app-access/DEPLOYMENT.md`
and preserve access wrappers, current modules, bindings and settings. This
preflight does not establish fresh APK-signature, physical-device or network
acceptance.
